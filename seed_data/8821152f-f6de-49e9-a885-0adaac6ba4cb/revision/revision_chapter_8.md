# Revision Notes — Chapter 8: The Word RAM Model

## Key Exam Takeaways

- The Word RAM model assumes random access to memory in constant time.
- Computers are byte-addressable, meaning addresses correspond to 8-bit chunks.
- Word size determines the maximum addressable memory space (e.g., 32-bit limits to 4GB, 64-bit to 20 exabytes).
- CPU operations (arithmetic, logic, memory access) are modeled as taking constant time on a constant amount of information.

## Core Concepts Breakdown

- **Word RAM**: A theoretical model of computation where memory is accessed randomly in constant time and operations are performed on fixed-size words.
- **Word Size**: The fixed number of bits (e.g., 64) that a CPU can retrieve from memory and process as a single unit.
- **Byte Addressable**: A memory architecture where each unique address refers to a specific 8-bit byte rather than an individual bit.
