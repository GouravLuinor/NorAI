# Revision Notes — Chapter 7: Common Running Time Functions

## Key Exam Takeaways

- Polynomial time ($\Theta(N^C)$) is generally considered efficient in this course.
- Exponential time ($2^{\Theta(N)}$) is considered inefficient due to its rapid growth.
- Logarithmic time is highly efficient, appearing nearly constant at large scales.
- The Word RAM model is used to define operations that take constant time.
- Growth rates are compared by plotting running time against input size $N$.

## Core Concepts Breakdown

- **Constant time**: A running time that does not change regardless of the input size.
- **Linear time**: A running time that grows proportionally to the input size, denoted as $\Theta(N)$.
- **Polynomial time**: A running time of $\Theta(N^C)$ for a constant $C$, generally considered efficient.
- **Exponential time**: A running time where a constant is raised to a function of $N$, considered inefficient.
