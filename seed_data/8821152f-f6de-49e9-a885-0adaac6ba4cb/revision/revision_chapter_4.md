# Revision Notes — Chapter 4: Example: The Birthday Problem

## Key Exam Takeaways

- The birthday problem algorithm relies on maintaining a dynamic record of birthdays as students are interviewed sequentially.
- The procedure checks for a match against the record for every new input; if found, it terminates immediately.
- If no match is found after checking all students, the algorithm concludes that no pair exists.
- An algorithm is defined as a procedure that maps inputs to a single correct output, functioning as a plan for solving a problem.

## Core Concepts Breakdown

- **Birthday Problem**: A problem requiring the identification of a pair of individuals within a group who share the same birthday.
- **Algorithm Procedure**: A step-by-step plan that takes an input and produces a correct output through a defined sequence of actions.
- **Record Maintenance**: The process of storing and checking data points (birthdays) to determine if a condition (a match) has been met.
