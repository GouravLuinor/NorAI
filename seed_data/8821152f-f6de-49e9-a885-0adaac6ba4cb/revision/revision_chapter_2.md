# Revision Notes — Chapter 2: Defining Computational Problems

## Key Exam Takeaways

- A computational problem is a binary relation between an input set and an output set.
- The relationship can be visualized as a bipartite graph where edges denote valid output(s) for a given input.
- A single input may have multiple valid outputs.
- Predicates are used to verify the correctness of an output for a given input, avoiding the need to list every possible pair.
- Generalizing problems allows for reasoning about large or variable input spaces, such as the pigeonhole principle applied to birthdays.

## Core Concepts Breakdown

- **Input space**: The set of all possible inputs that can be provided to a computational algorithm.
- **Output space**: The set of all possible results that can be produced by an algorithm.
- **Binary relation**: A mapping between inputs and outputs that specifies which outputs are considered correct for a given input.
- **Predicates**: A logical condition used to verify if a specific output is correct for a given input.
