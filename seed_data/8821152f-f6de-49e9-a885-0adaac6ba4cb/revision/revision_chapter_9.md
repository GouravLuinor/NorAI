# Revision Notes — Chapter 9: Data Structures and Course Overview

## Key Exam Takeaways

- Data structures are designed to manage large, non-constant amounts of data efficiently.
- Static arrays are a foundational data structure for record maintenance.
- Algorithmic problem-solving relies on two main strategies: reduction to known problems or designing custom recursive algorithms.
- The course is divided into three parts: data structures/sorting, graph algorithms, and dynamic programming.

## Core Concepts Breakdown

- **Data Structures**: Methods for storing and organizing large amounts of data to support efficient operations.
- **Static Array**: A basic data structure used to store a fixed-size collection of elements.
- **Recursive Algorithms**: A design paradigm where an algorithm solves a problem by calling itself on smaller sub-problems.
- **Reduction**: A problem-solving strategy that transforms a new problem into a known problem with an existing solution.
