# Revision Notes — Chapter 3: Generalizing Problems and Algorithms

## Key Exam Takeaways

- Algorithms must handle arbitrarily sized inputs rather than being limited to fixed-size datasets.
- An algorithm is a procedure or function that maps every valid input to a correct output.
- Correctness requires that for every input in the domain, the algorithm produces a valid output defined by the problem.
- Generalizing problems allows for the creation of robust, scalable computational solutions.

## Core Concepts Breakdown

- **Arbitrarily sized inputs**: The requirement that an algorithm must function correctly regardless of the size or scale of the input data provided.
- **Algorithm as a function**: A conceptual model where an algorithm is viewed as a mapping from a set of inputs to a set of correct outputs.
- **Deterministic algorithm**: A procedure that reliably and consistently produces a correct output for any given input within the problem domain.
