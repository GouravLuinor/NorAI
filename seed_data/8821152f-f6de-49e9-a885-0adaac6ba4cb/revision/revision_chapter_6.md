# Revision Notes — Chapter 6: Efficiency and Asymptotic Analysis

## Key Exam Takeaways

- Efficiency is measured by counting fundamental operations, not by timing execution on specific hardware.
- Performance is analyzed relative to the size of the input (often denoted as N).
- Input size definitions vary by context, such as N^2 for an N x N array or vertices plus edges for a graph.
- Asymptotic notation provides bounds: Big O (upper), Omega (lower), and Theta (tight).
- Linear time algorithms exhibit performance that scales linearly with the input size.

## Core Concepts Breakdown

- **Efficiency**: A measure of an algorithm's performance based on the number of fundamental operations required rather than raw execution time.
- **Asymptotic Analysis**: A method of describing the performance of an algorithm relative to the size of its input using mathematical notation.
- **Big O Notation**: A mathematical notation used to describe the upper bound of an algorithm's growth rate.
- **Input Size**: The amount of information or data provided to an algorithm, often denoted as N, which determines how performance scales.
