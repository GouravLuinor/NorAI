# Revision Notes — Chapter 5: Kinematics and One-Dimensional Motion

## Key Exam Takeaways

- Kinematics describes the current state of a system (position, speed) without explaining why motion occurs.
- Dynamics explains the causes of motion, such as forces like gravity.
- A mathematical point particle is an object with no spatial extent, simplifying analysis by ignoring rotation.
- One-dimensional motion restricts a particle to movement along a single line (the x-axis).
- Consistent use of units (meters for length, seconds for time) is mandatory for physical meaning.

## Core Concepts Breakdown

- **Kinematics**: The branch of mechanics that provides a complete description of a system's current state of motion.
- **Dynamics**: The study of the forces and causes that result in changes to an object's motion.
- **Mathematical point particle**: An idealized object with no size or spatial extent, used to simplify mechanical analysis.
- **One-dimensional motion**: The simplest form of motion where an object is constrained to move along a single straight line.
