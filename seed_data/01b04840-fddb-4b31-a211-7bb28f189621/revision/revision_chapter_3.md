# Revision Notes — Chapter 3: The Derivative Formula

## Key Exam Takeaways

- The slope of a secant line is the ratio of the change in function value (delta f) to the change in input (delta x).
- The derivative is defined as the limit of the secant line's slope as the horizontal distance (delta x) approaches zero.
- The formal derivative formula is f'(x0) = limit as delta x approaches 0 of [f(x0 + delta x) - f(x0)] / delta x.
- This formula allows for the calculation of the tangent line slope at any point x0 for a given function.

## Core Concepts Breakdown

- **Delta x**: The horizontal distance or change in the x-coordinate between two points on a curve.
- **Delta f**: The vertical distance or change in the function value between two points on a curve.
- **Difference quotient**: The ratio of the change in function value to the change in x, representing the slope of a secant line.
- **Derivative definition**: The limit of the difference quotient as delta x approaches zero, defining the slope of the tangent line.
