# Revision Notes — Chapter 1: Foundations of Neural Network Architecture

## Key Exam Takeaways

- Neural networks are mathematical structures designed to map inputs to outputs, not just biological simulations.
- A 28x28 pixel image requires 784 input neurons, with activations normalized between 0 (black) and 1 (white).
- The output layer consists of 10 neurons, each representing the confidence level for a digit (0-9).
- Network architecture (hidden layers/neurons) is flexible and determined experimentally.

## Core Concepts Breakdown

- **Activation**: A numerical value between 0 and 1 held by a neuron, representing its state or intensity.
- **Input Layer**: The initial layer of a neural network that receives raw data, such as pixel intensities from an image.
- **Hidden Layers**: Intermediate layers between input and output that perform the mathematical transformations necessary for pattern recognition.
- **Output Layer**: The final layer of the network that provides the classification result, typically representing confidence scores for categories.
