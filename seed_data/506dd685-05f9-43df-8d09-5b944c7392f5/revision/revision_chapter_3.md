# Revision Notes — Chapter 3: Benchmarking Performance, Latency, and Usability

## Key Exam Takeaways

- Latency is often more critical to user experience than raw benchmark scores.
- Long-context optimization significantly reduces memory growth and request volume.
- GLM 5.3 is a viable coding tool but underperforms in UI/UX tasks compared to Entropic models.
- Efficiency gains in modern LLMs are driven by reduced rendering overhead and optimized data loading.

## Core Concepts Breakdown

- **Latency**: The time delay between a user's request and the model's response, which is a primary driver of perceived application quality.
- **Memory Footprint**: The total system resources consumed by an LLM, which must be minimized to support long-context conversations effectively.
- **Long-context Handling**: The ability of an LLM to process and maintain large amounts of conversation history without significant performance degradation.
