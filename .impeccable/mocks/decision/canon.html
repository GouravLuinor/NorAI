The challenge of image recognition 0:04

Recognising handwritten digits is the "hello world" of neural networks; the pixels of the same digit vary too much between writers for a hand-written program.

The input layer 1:52

A 28 × 28 grayscale image gives the input layer 784 neurons, one per pixel, each holding a value from 0 to 1.

Why does the input layer have exactly 784 neurons?
The network reads a 28 × 28 image and each neuron holds one pixel: 28 × 28 = 784. (1:52)
