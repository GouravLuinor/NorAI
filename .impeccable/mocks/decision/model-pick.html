Chapter 1 · 0:04–5:04

The challenge of image recognition 0:04

Recognising handwritten digits is the "hello world" of neural networks. People read a 3 in any handwriting; a hand-written program cannot, because the pixels of the same digit vary too much between writers.

The input layer 1:52

A 28 × 28 grayscale image gives the input layer 784 neurons, one per pixel. Each holds a number between 0 for black and 1 for white: its activation.

Layers at a glance 3:28

Input 784 · two hidden layers of 16, chosen by experiment · output 10, one per digit.

Why does the input layer have exactly 784 neurons?
Because the network reads a 28 × 28 pixel image and each neuron holds one pixel's brightness: 28 × 28 = 784. I highlighted the line in your notes 1:52.
