1.10:04

The challenge of image recognition

Recognising handwritten digits is the "hello world" of neural networks. People read a 3 in any handwriting without effort; a hand-written program cannot, because the pixels of the same digit vary too much from one writer to the next.

1.21:52

The input layer

A 28 × 28 grayscale image gives the input layer 784 neurons, one per pixel. Each holds a number between 0 for black and 1 for white: its activation.

1.33:28

Layers at a glance

Input 784 · two hidden layers of 16, chosen by experiment · output 10, one per digit.

Why does the input layer have exactly 784 neurons?
Because the network reads a 28 × 28 pixel image, and each neuron holds one pixel's brightness: 28 × 28 = 784 1.2 · 1:52. The lecture shows the grid on the slide right after 2:10.
