# Architecture Decisions

## API-First Design

The frontend never communicates directly with LangGraph.

All interactions pass through FastAPI.

This cleanly separates:

- presentation
- orchestration
- AI reasoning

---

## Persistent Conversations

Conversation history is owned by the backend.

The frontend restores threads rather than managing conversation persistence itself.

---

## Static Educational Resources

Revision notes, study notes, and flashcards are generated offline.

The backend simply serves them.

Advantages:

- lower latency
- lower API cost
- deterministic educational content

---

## LangGraph Isolation

LangGraph remains completely independent of the frontend.

Future interfaces (mobile, desktop, API clients) can reuse the same backend without modification.
