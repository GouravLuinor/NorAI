**Method:** 10 parallel read-only audit agents — frontend UI/UX (vs `norai-frontend-standards`), frontend code quality, backend core quality (5-axis), tutor/RAG module, security sweep (OWASP + LLM Top 10), performance (both ends), architecture/dead-code, Tier-0 pattern extraction (`~/coding/startup/tier0`).

**Recurring themes**

1. **AuthZ gaps around "demo/default" convenience paths** — thread persistence, quiz evaluation, guest identities, and dev flags all bypass ownership or quota checks.
2. **Copy-paste drift** — NotesView/RevisionView twins, three hand-rolled SSE clients, four `genId`s, three Gemini client constructions, duplicated retry regimes. Bugs fixed in one copy still live in others (the dead Copy button proves it).
3. **Silent degradation everywhere** — `.catch(() => {})`, disk-before-DB job status, auth exceptions → anonymous, LLM parse failures → HTTP 200 with nulls. The app rarely fails loudly when it should.
4. **Token-system discipline is good but leaky** — a real token ramp exists, yet raw palette colors, fake utilities (`text-22-bold`), and arbitrary radii/durations bypass it in high-traffic spots.

Clean areas worth noting (verified): secrets hygiene (nothing real ever committed, history checked), SQL parameterization throughout, path-traversal defenses (`sanitize_lecture_id` + `resolve()/relative_to()`), SSRF host allowlisting on URL fetches, webhook signature verification, XSS discipline (react-markdown escaping, zero `dangerouslySetInnerHTML`), reduced-motion support at three levels, offline-safe backend test suite, Alembic auto-run at startup with current coverage.

## 2. Findings by Category

### 2.1 Security

**Secrets & environment**
- `[P]` `.gitignore:22-26` — correctly ignores `.env`, `.env.local`, `.env.*.local`, `.env.production`; `git ls-files` confirms only `.env.example` tracked. History verified clean. No action.
- `[m]` Dockerfile:48-58 — `bgutil-pot` binary fetched from GitHub releases pinned by tag, never checksum-verified. A compromised upstream release ships a backdoored binary into every production image. Fix: record sha256 digests beside `BGUTIL_POT_VERSION` and `sha256sum -c` before install.
- `[P]` requirements.txt exact-pinned ✓, single JS lockfile enforced via `npm ci` ✓; but no hash-pinning for pip and no scheduled `pip-audit`/`npm audit` CI job. Fix: adopt `--require-hashes` (or pip-tools/uv) + a triaged audit job.

**Authentication & authorization**
- `[C]` backend/auth.py:60-65 — `NORAI_DEV_INSECURE_AUTH=1` decodes JWTs with **signature verification disabled** → any `sub` claim impersonates any account. Nothing blocks this flag when `NORAI_ENV=production`. Fix: hard-refuse boot (or scream-and-disable) when dev flags are set in production; flip `.env.example:35` default to `NORAI_DEV_ACCESS=0`.
- `[C]` backend/main.py:803-824 — unauthenticated `DELETE /threads/{thread_id}` wipes any lecture's checkpoint/user_threads tables by ID guess. Fix: add `ensure_lecture_access` write gate like sibling routes.
- `[M]` main.py:667-824 — entire thread surface (`GET /threads` :668, `POST /threads` :720, `GET /threads/{id}` :749, `DELETE` :804) takes no user dep and no access gate; contrast `/quiz/questions` :836-839 which correctly calls `ensure_lecture_access`. Strangers read/write each other's private conversations. Fix: require auth + `ensure_lecture_access`; scope reads behind the same `allow_tutor_chat` gate as `/chat`.
- `[M]` main.py:2757-2794 — `POST /process/{task_id}/cancel` and `GET /process/{task_id}/status` skip ownership checks; raw pipeline exception text (`str(exc)[:4000]`, jobs.py:392-398 → main.py:2776-2780) returned verbatim, leaking paths/library versions. Fix: verify `Lecture.user_id == user.id`; map failures to friendly stage messages, keep tracebacks server-side.
- `[M]` auth.py:201-214,217-267 — client-minted `X-Guest-Id` creates a fresh User + 15-min-trial Subscription per unique header value → unlimited free-tier resets (free compute abuse). Fix: cap/rate-limit guest rows per IP; sign device IDs.
- `[M]` quiz_attempts & flashcard ratings (main.py:1017-1310 region) — rows carry no `user_id`; share-link viewers can read/poison each other's review state. Fix: add owner columns + scoping.
- `[m]` main.py:800 — `GET /threads/{thread_id}` re-raises `HTTPException(detail=str(e))` leaking internal details. Fix: generic 500 detail; log server-side.
- `[P]` dependencies.py:131-142 — shared `"default"` tutor store (`outputs/tutor/checkpoints.sqlite`) is one world-writable conversation space for anonymous demo visitors. Document as intentionally public data (LLM08).

**Rate limiting & abuse**
- `[M]` ratelimit.py:8-38 — sliding-window throttle exists for **outbound Gemini calls only**. Zero inbound HTTP rate limiting anywhere; sole 429s are billing-quota checks (main.py:1887,1897,1903). Unprotected expensive routes: `POST /quiz/evaluate` (:864 free LLM call), `/threads*`, `/estimate`, `/process/{id}/cancel`, and `/chat`/`/chat/stream` (access-gated but not request-limited). Fix: slowapi (or equivalent) limits on chat/quiz/process/estimate; pre-spend remaining-quota check inside `/chat` for demo/default lectures (main.py:1586 short-circuit); cap question/persona lengths.

**CORS & headers**
- `[M]` main.py:320-327 — credentialed (`allow_credentials=True` :324, methods/headers `"*"`) CORS with `allow_origin_regex=r"https://.*\.onrender\.com"` active whenever `NORAI_ENV != "production"` (:205). Any attacker-deployed `*.onrender.com` app passes the regex on staging/misconfigured deploys. Fix: fail closed — regex off unless explicitly non-prod; drop the wildcard-render rule entirely (delete the `*.onrender.com` entry).
- `[M]` No security headers emitted anywhere (grep: zero CSP/XFO/XCTO/HSTS/Referrer-Policy/Permissions-Policy). Share/billing pages framable (clickjacking), responses MIME-sniffable. Fix: small middleware after CORS setting `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`, a conservative CSP, HSTS behind TLS.
- Debug surfaces OK: `/docs` disabled in production (main.py:205-213), generic 500 handler (:291-297). SPA catch-all traversal containment verified clean (main.py:2803-2807).

**Input validation & uploads**
- Upload endpoint (main.py:1911-1941): size cap 2GB enforced during streamed writes ✓, extension allowlist `{.mp4,.mkv,.avi,.mov,.webm}` ✓, filename sanitized + uuid-prefixed ✓. **Missing**: content-type check and magic-byte sniff. Fix: sniff container signatures before accepting.
- `[m]` video_map.py:104-106 — uncaught `int(cid)` ValueError → 500 on `/video-map`. Fix: guarded parse.

**Client-side leaks & XSS surfaces**
- `[M]` frontend/src/lib/markdown.tsx:105-117 (+ cleanImageSrc :29-37) — custom `img` renderer accepts arbitrary remote `http(s)` sources in rendered markdown (notes/chat/shared links) → tracking pixels leak viewer IP/referrer; no `referrerPolicy`. **Webhooks & SSRF** — webhook signature verification implemented and tested for the pure path (routers/webhooks.py; test_webhooks.py:37-44 covers only `verify_signature`). SSRF: server-side URL fetches host-allowlisted ✓.
